
================================================================================
                    GapONet 强化学习训练逻辑分析报告
================================================================================

【1. GapONet 是否使用强化学习方法？】

是的，GapONet 是一个基于强化学习（Reinforcement Learning, RL）的机器人控制框架。

证据如下：

1) 使用 RSL-RL 框架
   - 训练入口: scripts/rsl_rl/train.py
   - 核心运行器: sim2real.rsl_rl.runners.OperatorRunner
   - 算法: PPO (Proximal Policy Optimization)

2) 典型的 RL 组件
   - 环境交互: env.step(actions)
   - 奖励函数: _get_rewards()
   - 策略网络: Actor-Critic 架构 (DeepONet)
   - 经验回放: replay_buffer
   - PPO 更新: 策略梯度 + 值函数估计

3) 训练循环
   from scripts/rsl_rl/train.py:
   ```python
   runner.learn(num_learning_iterations=agent_cfg.max_iterations, init_at_random_ep_len=True)
   ```

================================================================================
                    2. 主要训练目标及数学形式化
================================================================================

【训练目标】

GapONet 的主要训练目标是：让机器人学习一个策略，能够精确跟踪参考运动轨迹（motion tracking）。

【数学形式化】

这是一个标准的 RL 问题：

1) 状态空间 (Observation Space):
   - operator observation: {branch, trunk, critic}
   - model observation: 机器人关节状态 + 历史信息

2) 动作空间 (Action Space):
   - delta_action: 相对于参考动作的增量 (Δθ)
   - 实际应用: action = reference_action + delta_action

3) 奖励函数:
   r(s, a) = -k * tracking_error
   
   其中:
   - k = (36 / (2π))^2 ≈ 32.7 (弧度到度的转换系数平方)
   - tracking_error = position_error + 0.01 * velocity_error

4) 目标: 最大化期望累积奖励
   J(π) = E_τ~π[Σ γ^t r(s_t, a_t)]

5) 使用 PPO 算法优化策略:
   L(θ) = E[min(r_t(θ) * A_t, clip(r_t(θ), 1-ε, 1+ε) * A_t)]

================================================================================
                    3. 奖励函数结构分析
================================================================================

【奖励函数代码】

来自 humanoid_operator_env_fourior.py:

```python
def _get_rewards(self) -> torch.Tensor:
    return - ((36 / (2 * torch.pi)) ** 2) * self._reward_tracking()
```

【_reward_tracking() 详细实现】

```python
def _reward_tracking(self):
    # 机器人当前状态
    robot_dof_positions = self.robot.data.joint_pos
    robot_dof_velocities = self.robot.data.joint_vel

    # 从 MotionLoader 采样的参考状态
    real_dof_positions = self._motion_loader.dof_positions[motion_indices, time_indices]
    real_dof_velocities = self._motion_loader.dof_velocities[motion_indices, time_indices]
    
    joint_index = self._motion_loader.joint_sequence_index

    # 计算奖励
    position_diff = (robot_dof_positions - real_dof_positions) ** 2
    velocity_diff = (robot_dof_velocities - real_dof_velocities) ** 2
    
    # 只关注训练关节 (joint_sequence_index)
    position_diff = torch.mean(position_diff[:, joint_index], dim=1)
    velocity_diff = torch.mean(velocity_diff[:, joint_index], dim=1)

    return position_diff + velocity_diff * 1e-2
```

【奖励组成】

| 组件 | 公式 | 权重 |
|------|------|------|
| 位置跟踪误差 | (θ_robot - θ_target)^2 | 1.0 |
| 速度跟踪误差 | (ω_robot - ω_target)^2 | 0.01 |
| 缩放系数 | (36/2π)^2 ≈ 32.7 | 全局缩放 |

【最终奖励】

r = -缩放系数 × (位置误差 + 0.01 × 速度误差)

注意：奖励为负值，RL 算法会最大化这个值，即最小化跟踪误差。

================================================================================
                    4. Delta 参数的作用与意义
================================================================================

【什么是 Delta Action？】

Delta action（增量动作）是 GapONet 的核心设计：

- 传统方法: 直接输出目标关节位置 θ_target
- GapONet: 输出相对于参考动作的增量 Δθ

【Delta 的数学定义】

```
final_action = reference_action + delta_action
              = motion_target + Δθ
```

【为什么使用 Delta？】

1) 降低策略学习难度
   - 增量变化比绝对位置更容易学习
   - 网络只需学习"如何修正"而非"要做什么"

2) 提高训练稳定性
   - 参考动作提供了良好的初始估计
   - 网络可以在参考基础上微调

3) Sim-to-Real 迁移
   - 真实机器人可以提供参考轨迹
   - 策略学习补偿动力学不确定性

【代码实现】

```python
# humanoid_operator_env.py step_operator()
def step_operator(self, delta_action: torch.Tensor, ...):
    self.delta_action[:] = delta_action
    
    # 获取参考动作（目标关节位置）
    self.apply_action[:] = self._motion_loader.dof_target_pos[motion_indices, time_indices]
    
    # 添加 delta
    self.apply_action[:, joint_sequence_index] += self.delta_action
    
    # 发送到机器人
    self.robot.set_joint_position_target(self.apply_action)
```

【Delta 的维度】

- 来自策略网络输出: action_dim = action_space (配置中为 31 或 10)
- 实际应用时添加到对应的关节索引上

```

│                                                                  │

│  │   │     ├─ branch_obs: sensor_data.flatten          │    │
```

================================================================================
                    6. RL 框架与实现细节
================================================================================

【使用的 RL 框架】

GapONet 基于 RSL-RL (Rising Star Robot Learning) 框架实现。

【RSL-RL 核心组件】

1) OnPolicyRunner
   - 来自 rsl_rl.runners.OnPolicyRunner
   - 管理训练循环、环境交互、策略更新

2) OperatorRunner (自定义)
   - 继承自 OnPolicyRunner
   - 适配人形机器人操作任务
   - 支持传感器模型学习

3) PPO 算法
   - Proximal Policy Optimization
   - 来自 rsl_rl.algorithms
   - 使用 clip 防止策略更新过大

4) DeepONet Actor-Critic (自定义网络)
   - 来自 sim2real.rsl_rl.modules.DeepONetActorCritic
   - Branch + Trunk 架构
   - 适合处理操作任务

【网络架构图】

```

    输入 (Observation)
          │
          ├──────────────────────────┐
          │                          │

   ┌─────────────┐           ┌─────────────┐
   │ Branch Net  │           │ Trunk Net   │
   │ (传感器)    │           │ (动作)      │

Sensor Model (动力学建模)
    输入: robot_state (pos, vel, target)
    输出: predicted_sensor
    用途: 补偿 sim-to-real 差异
```

【关键配置参数】

来自 rsl_rl_operator_cfg.py:

```python
@configclass
class HumanoidOperatorRunnerCfg(RslRlOnPolicyRunnerCfg):
    num_steps_per_env = 32          # 每次采集的步数
    num_steps_function = 1           # 每个函数采样的步数
    max_iterations = 120            # 最大训练迭代次数
    save_interval = 50               # 保存间隔
    
    # PPO 参数
    algorithm = RslRlPpoAlgorithmCfg(
        learning_rate=1.0e-4,
        gamma=0.99,                 # 折扣因子
        lam=0.95,                   # GAE 参数
        clip_param=0.2,             # PPO clip 范围
        num_learning_epochs=5,
        num_mini_batches=4,
    )
    
    # 传感器模型参数
    model_based_sensor = True       # 启用传感器模型
    model_learning_epochs = 300
    model_learning_interval = 1000
```

================================================================================
                    7. 总结
================================================================================

GapONet 是一个完整的强化学习框架，用于人形机器人控制：

1) 方法: ✓ 基于 PPO 的强化学习
2) 目标: 最小化运动跟踪误差 (r = -error)
3) 奖励: 位置误差 + 速度误差的加权和
4) Delta: 相对于参考轨迹的增量动作
5) 框架: RSL-RL + DeepONet
6) 特色: 支持传感器模型学习，辅助 sim-to-real 迁移
